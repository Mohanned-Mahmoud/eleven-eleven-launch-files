# Music files

Upload your own permitted audio files here, with these exact lowercase names:

- `calm.mp3` — هادي
- `hyper.mp3` — مهيبر

Use actual MP3 files, not Spotify links or renamed video files. Commit them to
GitHub and let Vercel redeploy. No environment variable edits are needed for
these filenames. Only files present in the deployment appear in the audio menu.
Selecting music changes audio only. Playback starts with a tap.

This repository is public: uploaded files are publicly accessible on GitHub.
The deployed website still applies its server-side launch gate to audio URLs.
