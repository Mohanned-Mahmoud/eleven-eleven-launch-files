# Phase 1 implementation plan

1. Inspect the workspace and establish a fresh React + Vite + TypeScript project.
2. Curate real, licensed rose and garden photographs; choose portrait crops before building.
3. Build the shared configuration, tokens, layout, typography, motion utilities and scene manager.
4. Create the countdown, opening and photographic garden prototypes. Keep growth mechanics out of scope.
5. Add development-only scene selection and a deterministic preview clock; strip both from production.
6. Run the dev server, capture all three scenes at the five specified sizes, inspect the actual renders and refine.
7. Verify timing, navigation, accessibility behavior and production output. Package source, screenshots and handoff notes.
